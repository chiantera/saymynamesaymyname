# Implementation guides

Read [current status](../../CURRENT-TASK.md) before treating a guide as a release
claim. These guides describe implemented contracts and remaining gates; the
[product plan](../../PLAN.md) defines accepted behavior across later phases.

- [Phase 0/1](PHASE-0-1.md): bounded scope, acceptance and release checklist.
- [Cloud auth](CLOUD-AUTH-SETUP.md): configuration, recovery and evidence boundaries.
- [Membership](MEMBERSHIP.md): unanimity, recipient-bound tokens and pairwise blocks.
- [Sharing](SHARING.md): explicit fixed-copy grants and revocation.
- [Cloud scheduling](CLOUD-SCHEDULING.md): jobs, leases, static free consumer and Render switch-over.
- [Free cloud research](FREE-CLOUD-RESEARCH.md): Frankfurt worker and storage options, costs and limits.
- [Local AI worker](LOCAL-WORKER.md): testing-time restricted AI worker on the operator's machine.
- [AI consent](AI-CONSENT.md): saved-source preferences and processor/capability review.
- [AI budget](AI-BUDGET.md): exact reservations, unknown holds and reconciliation.
- [DeepSeek adapter](DEEPSEEK-ADAPTER.md): dormant fixed-input composition and accounting.
- [Safety worker](SAFETY-WORKER.md): reviewed assessment and publication fences.
- [Crisis support](CRISIS-SUPPORT.md): curated resources, review gates and private notices.
- [Private edit recovery](EDIT-RECOVERY.md): owner-only copies, tombstones and active-draft limits.
- [Polling](POLLING.md): bounded refreshes, visibility and account-generation checks.
- [Security headers](SECURITY-HEADERS.md): enforced policy and browser/hosted verification.
- [Frontend overhaul](FRONTEND-OVERHAUL.md): design integration and test coverage.

[Testing](../TESTING.md) reports command prerequisites; [changelog](../CHANGELOG.md)
keeps dated milestones. Live AI, paid hosting, native push and beta readiness remain
separate claims requiring explicit evidence.
