# 0004 — Documentation authority and history

Accepted 2026-11-17. Keep one short current-status page, one agent guide (CLAUDE
points to AGENTS), a concise dated changelog and a topic index for the preserved
numbered specifications. Implementation guides own code/runbook details; folder
READMEs explain local responsibilities and link to those sources.

Preserve accepted decisions and evidence boundaries when reorganizing. Keep raw
operational/account evidence in an ignored private archive; do not change repository
visibility or rewrite history as a side effect. Commands report test totals rather
than manually duplicating them in prose. Validate local Markdown links and authority
contracts in the normal check pipeline. [Documentation map](../README.md).
