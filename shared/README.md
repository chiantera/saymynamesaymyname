# Shared resources

[Locale catalogs](locales/README.md) supply UI and static mock prompt/draft text.
`crisis-resources.json` is the curated regional directory with source verification,
expiry and professional-copy review gates. It contains no user-selected country,
private story, secret or per-user memory.

Language is not location. Unknown/stale contact facts never produce a guessed dial
button. External directories load only on user action. Review dates cannot be
extended without checking primary sources. [Resource maintenance](../docs/implementation/CRISIS-SUPPORT.md).
